# Laboratoire de Sécurité Web 🔒

Environnement d'apprentissage interactif pour comprendre les vulnérabilités web et les permissions du navigateur.

## ⚠️ AVERTISSEMENT IMPORTANT

**Ce projet est STRICTEMENT à des fins éducatives.**

- ✅ Utilisez-le pour **apprendre** la sécurité web
- ✅ Testez uniquement sur **vos propres systèmes**
- ✅ Environnement **local isolé** (localhost)
- ❌ **INTERDIT** d'utiliser ces techniques contre des systèmes sans autorisation
- ❌ L'utilisation malveillante est **ILLÉGALE** et punissable par la loi

**L'auteur décline toute responsabilité en cas d'utilisation abusive.**

## Structure du Projet

- `permissions-navigateur/` - Exemples de permissions (caméra, micro, géolocalisation)
- `vulnerabilites/` - Démonstrations XSS, CSRF, injection SQL
- `securise/` - Versions sécurisées des mêmes fonctionnalités
- `owasp-top10/` - Exemples pour chaque vulnérabilité OWASP

## Démarrage Rapide

```bash
# Installer les dépendances
npm install

# Lancer le serveur local
npm start
```

Le serveur démarre sur http://localhost:3000

## Modules d'Apprentissage

### 1. Permissions du Navigateur
- Demande de permission caméra/microphone
- Géolocalisation
