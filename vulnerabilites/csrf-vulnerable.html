Qu'est-ce que CSRF?

Cross-Site Request Forgery (CSRF) est une attaque qui force un utilisateur authentifié à effectuer une action non désirée sur une application web.

L'attaquant exploite la confiance qu'une application a envers le navigateur de l'utilisateur.

Simulation: Transfert Bancaire (VULNÉRABLE)

Scénario: Vous êtes connecté à votre banque en ligne.

1000€

Comment fonctionne l'attaque?

  1. La victime est connectée à son site bancaire (authentifiée)
  2. L'attaquant envoie un lien malveillant à la victime
  3. Le lien contient une requête de transfert forgée
  4. Puisque la victime est authentifiée, la requête est exécutée
  5. L'argent est transféré sans le consentement de la victime

Exemples d'Attaques CSRF

1. Via une image cachée:

<img src="https://bank.com/transfer?to=attacker&amount=1000" style="display:none">

2. Via un formulaire auto-submit:

<form action="https://bank.com/transfer" method="POST">
  <input type="hidden" name="to" value="attacker">
  <input type="hidden" name="amount" value="1000">
</form>
<script>document.forms[0].submit();</script>

3. Via fetch/AJAX:

fetch('https://bank.com/transfer', {
  method: 'POST',
  body: JSON.stringify({to: 'attacker', amount: 1000})
});

Pourquoi c'est dangereux?

  • 💸 Transferts d'argent non autorisés
  • 🔐 Changement de mot de passe
  • 📧 Changement d'email
  • 🗑️ Suppression de données
  • 👥 Actions sur les réseaux sociaux (posts, likes, follows)
  • ⚙️ Modification de paramètres
