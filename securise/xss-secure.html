✅ Cette page est PROTÉGÉE contre XSS

Toutes les entrées utilisateur sont sanitisées et échappées.

Protections Implémentées

  • ✅ Content Security Policy (CSP) dans les headers
  • ✅ Sanitisation de toutes les entrées utilisateur
  • ✅ Utilisation de textContent au lieu de innerHTML
  • ✅ Échappement HTML pour l'affichage
  • ✅ Validation des entrées

Test 1: Affichage Sécurisé

Essayez d'injecter du code malveillant - il sera affiché comme du texte.

Code sécurisé:
// Utilisation de textContent au lieu de innerHTML
output.textContent = input.value;

Test 2: Commentaires Sécurisés

Les commentaires sont stockés et affichés de manière sécurisée.



Solution:
// Échappement HTML avant affichage
const escaped = sanitizeHTML(comment);
// Ou utilisation de textContent

Test 3: Images Sécurisées

Les URLs sont validées avant utilisation.

Charger l'image (Sécurisé)
Code sécurisé:
// Création d'élément DOM + validation d'URL
const img = document.createElement('img');
img.src = validateURL(url);

❌ Code Vulnérable

element.innerHTML = userInput;

// Permet l'injection de code

✅ Code Sécurisé

element.textContent = userInput;

// Le code est affiché comme texte

Fonctions de Sanitisation

Échappement HTML:
function sanitizeHTML(str) {
  return str
    .replace(/&/g, '&')
    .replace(/</g, '&lt;')
    .replace(/>/g, '&gt;')
    .replace(/"/g, '&quot;')
    .replace(/'/g, '&#x27;')
    .replace(/\//g, '&#x2F;');
}

Headers de Sécurité

default-src 'self'; script-src 'self'
